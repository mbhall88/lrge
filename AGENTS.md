# AGENTS.md

Guidance for AI agents working in this repository.

`lrge` is a Rust workspace: the `lrge` binary crate (CLI) and the `liblrge` library crate, for genome size estimation from long read overlaps.

## Agent skills

### Writing

For all user-facing documentation, GitHub issue and pull request prose, and Git commit messages, run `/avoid-ai-writing` before finalizing the text.

### Commit messages

Releases and the changelog are generated by release-please from conventional commits, and it parses them strictly. Two things silently drop a commit out of the changelog:

- **Nested parentheses anywhere in the message.** `internal_filter(Some(0.0), ratio)` fails to parse and takes the whole commit with it, including its `BREAKING CHANGE:` note. Write the prose without them.
- **A subject that is not a conventional commit.** Pull requests are squash-merged and the squash body has been empty on every merge so far, so the PR *title* is usually the whole commit message release-please sees. Title pull requests as conventional commits, and put the `!` there when the change is breaking.

A commit release-please cannot parse is reported only as `commit could not be parsed` in the workflow log, so check the release pull request after merging anything breaking.
